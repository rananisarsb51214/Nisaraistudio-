# Quick Start Guide ⚡ 1 Minute Setup

## 🚀 Super Fast Setup (60 Seconds)

### Step 1: Copy CSV Data (10 sec)
- Download `NISAR_AI_BULK_30_DESIGNS.csv`
- Copy all rows

### Step 2: Create Google Sheet (15 sec)
1. Open [Google Sheets](https://sheets.google.com)
2. Create new sheet
3. Add headers from README.md → "Project Planner Sheet Headers"
4. Paste CSV data

### Step 3: Create Canva Template (20 sec)
1. Go to [Canva Pro](https://www.canva.com)
2. Create 5-page presentation (1080x1920)
3. Copy layout from README.md → "Master Prompt"
4. **Save as Template** → Get shareable link

### Step 4: Connect Bulk Create (15 sec)
1. Open Canva Template
2. **Apps** → Search "Bulk Create"
3. Connect Google Sheet
4. Click **Generate 30 Designs**
